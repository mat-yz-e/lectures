LangGraph’ta Map-Reduce: Send API ile Dinamik Fan-out ve Reducer ile Birleştirme

Bu ders, LangGraph’ta map-reduce deseninin Send API’siyle nasıl dinamik fan-out oluşturduğunu ve reducer tanımının paralel sonuçları nasıl tek state alanında birleştirdiğini açıklar.

Kapsam ve Bağlam

Bu bölümde amaç, bir görevi alt görevlere ayırıp bu alt görevleri paralel biçimde çalıştırdıktan sonra sonuçları tek bir kararda birleştiren map-reduce desenini LangGraph bağlamında anlamaktır. Örnek akış, kullanıcıdan gelen genel bir konu için alt konular üretir, her alt konu için ayrı bir şaka oluşturur ve son aşamada en iyi şakayı seçer.

Bu yapı, daha büyük çok ajanlı sistemlerde sık karşılaşılan bir ihtiyacı temsil eder: tek bir büyük görevi daha küçük bağımsız işlere bölmek, bağımsız işleri paralel yürütmek ve üretilen sonuçları denetlenebilir bir state sözleşmesi altında toplamaktır.

Bu Dersin Ana Tezi

Send, LangGraph’ta çalışma anında dinamik sayıda node çağrısı üretir; Annotated[list, operator.add] reducer’ı ise bu paralel çağrıların aynı state alanına güvenli biçimde eklenmesini sağlar.

Öğrenme Hedefleri

  • Map-reduce deseninde map ve reduce fazlarının LangGraph graph yürütmesine nasıl karşılık geldiğini açıklayabilecek.
  • Send("generate_joke", {"subject": s}) çağrısının neden dinamik fan-out oluşturduğunu yorumlayabilecek.
  • OverallState ve JokeState ayrımının mapped node tasarımına neden esneklik kattığını ayırt edebilecek.
  • Annotated[list, operator.add] reducer’ının paralel node çıktılarında hangi problemi çözdüğünü açıklayabilecek.
  • with_structured_output(...) kullanımının model çıktısını state güncellemesine daha uygun hale getirdiğini gösterebilecek.
  • Stream çıktısında generate_topics, çoklu generate_joke ve best_joke update’lerini okuyabilecek.

Ön Koşullar

Bu dersi takip etmek için Python fonksiyonları, dictionary ve list yapıları, type hint kullanımı, TypedDict, Annotated ve Pydantic BaseModel hakkında temel bilgi gerekir. LLM çağrıları için API anahtarı ve ortam değişkeni kavramını bilmek de önemlidir.

LangGraph açısından StateGraph, node, edge, conditional edge ve state update kavramları temel ön bilgidir. Reducer kavramı bu derste merkezi rol oynar: reducer, aynı state alanına birden fazla update geldiğinde bunların nasıl birleşeceğini belirleyen kuraldır.

Bu derste graph, sabit çizilmiş bir paralel topolojiyle başlamaz. Önce modelden alt konu listesi alınır; sonra bu listenin uzunluğuna göre Send nesneleri üretilir. Böylece graph, çalışma anındaki veri miktarına göre kaç adet map görevi çalıştıracağını belirler.

State’in Rolü

State burada local değişken değildir. Graph yürütmesi boyunca node’ların hangi alanları okuyacağını, hangi alanları yazacağını ve paralel update’lerin nasıl birleşeceğini belirleyen sözleşmedir.

Ana Anlatım

Map-reduce deseninin LangGraph karşılığı

Map fazı, ana işi bağımsız alt işlere böler. Bu derste ana iş “bir konu hakkında şaka üretmek”tir; alt işler ise modelin ürettiği her alt konu için tek bir şaka oluşturmaktır. Bu alt işler birbirine bağımlı olmadığı için paralel çalıştırılabilir.

Reduce fazı, map fazında oluşan sonuçları tek bir karar noktasına getirir. Burada tüm şakalar jokes listesinde birikir ve best_joke node’u bu liste üzerinden en iyi şakayı seçer.

Send API’nin kritik katkısı

Send API’si, graph tasarımında önceden kaç adet alt görev çizileceğini bilme zorunluluğunu ortadan kaldırır. Alt konu listesi üç elemanlıysa üç çağrı, beş elemanlıysa beş çağrı üretilebilir. Kodda bunun karşılığı, state["subjects"] listesi üzerinde dolaşıp her eleman için bir Send nesnesi oluşturmaktır.

Reducer neden zorunlu hale gelir?

Paralel map çağrılarının tamamı jokes alanına yazmak ister. Bu alan normal overwrite davranışıyla tanımlansaydı aynı adımda birden fazla update çakışabilirdi. Annotated[list, operator.add], LangGraph’a bu alan için liste birleştirme davranışını açıkça bildirir.

Structured output ve ana state şemasını kurma

Bu blok hem model çıktısının beklenen biçimini hem de graph’ın taşıyacağı ana state alanlarını tanımlar.

Structured output ve ana state şemasını kurma
import operator
from typing import Annotated

from pydantic import BaseModel
from typing_extensions import TypedDict


class Subjects(BaseModel):
    """
    Define the Subjects data model.
    """
    subjects: list[str]


class BestJoke(BaseModel):
    """
    Define the BestJoke data model.
    """
    id: int


class OverallState(TypedDict):
    """
    Define the state schema used by the graph.
    """
    topic: str
    subjects: list
    jokes: Annotated[list, operator.add]
    best_selected_joke: str

LangGraph açısından önemi

OverallState, graph boyunca taşınacak sözleşmedir. jokes alanındaki operator.add reducer’ı paralel yazımları tek listede birleştirir.

Dikkat edilmesi gereken nokta

Reducer yalnızca jokes alanına bağlanmıştır. subjects ve best_selected_joke alanları normal state update’i olarak yazılır.

Blok bazlı açıklama

Subjects ve BestJoke, LLM çıktılarının serbest metin yerine denetlenebilir alanlara ayrılmasını sağlar.

Alt konuları üretme node’u

İlk gerçek node, kullanıcı konusunu alır ve şaka üretilecek alt konu listesini modelden structured output olarak ister.

Alt konuları üretme node’u
def generate_topics(state: OverallState):
    """
    Run the generate_topics helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    prompt = subjects_prompt.format(topic=state["topic"])
    response = model.with_structured_output(Subjects).invoke(prompt)
    return {"subjects": response.subjects}

LangGraph açısından önemi

generate_topics, topic alanını okur ve subjects alanını yazar. Bu liste fan-out sayısını belirler.

Dikkat edilmesi gereken nokta

Node yalnızca değiştirdiği alanı döndürür. LangGraph’ta state update’i tüm state’in yeniden oluşturulması anlamına gelmez.

Send ile dinamik map yönlendirmesi

Bu blok, alt konu listesindeki her eleman için ayrı generate_joke çağrısı oluşturur.

Send ile dinamik map yönlendirmesi
from langgraph.types import Send


def continue_to_jokes(state: OverallState):
    """
    Run the continue_to_jokes helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    return [
        Send("generate_joke", {"subject": s})
        for s in state["subjects"]
    ]

LangGraph açısından önemi

Send, graph çiziminde sabit sayıda edge tanımlamadan çalışma anında birden çok node çağrısı üretir.

Dikkat edilmesi gereken nokta

Send içindeki state, ana OverallState ile birebir aynı olmak zorunda değildir. Burada mapped node’a yalnızca subject verilir.

Blok bazlı açıklama

Bu bölüm dersin map fazıdır: listeyi dolaşmak sadece Python list comprehension değildir; graph yürütmesinde paralel node çağrılarına dönüşür.

Her alt konu için şaka üretme node’u

Mapped node kendi küçük state sözleşmesini kullanır ve ürettiği şakayı ana state’teki reducer’lı listeye yazar.

Her alt konu için şaka üretme node’u
class JokeState(TypedDict):
    """
    Define the state schema used by the graph.
    """
    subject: str


class Joke(BaseModel):
    """
    Define the Joke data model.
    """
    joke: str


def generate_joke(state: JokeState):
    """
    Run the generate_joke helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    prompt = joke_prompt.format(subject=state["subject"])
    response = model.with_structured_output(Joke).invoke(prompt)
    return {"jokes": [response.joke]}

LangGraph açısından önemi

generate_joke, tek subject okur ve jokes alanına tek elemanlı liste döndürür. Reducer bu listeleri birleştirir.

Dikkat edilmesi gereken nokta

Dönen değerin {"jokes": [response.joke]} biçiminde liste olması önemlidir; reducer liste toplama semantiğiyle çalışır.

Reduce fazında en iyi şakayı seçme

Map fazında toplanan şakalar tek metne dönüştürülür ve modelden en iyi adayın indeksini seçmesi istenir.

Reduce fazında en iyi şakayı seçme
def best_joke(state: OverallState):
    """
    Run the best_joke helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    jokes = "\n\n".join(state["jokes"])
    prompt = best_joke_prompt.format(topic=state["topic"], jokes=jokes)
    response = model.with_structured_output(BestJoke).invoke(prompt)
    return {"best_selected_joke": state["jokes"][response.id]}

LangGraph açısından önemi

best_joke, biriken jokes listesini okur ve nihai best_selected_joke alanını yazar.

Dikkat edilmesi gereken nokta

Kod, modelin döndürdüğü indeksin geçerli olduğunu varsayar. Materyalde sınır dışı indeks için ayrı hata yönetimi tanımlanmıyor.

Blok bazlı açıklama

Bu bölüm reduce fazıdır: paralel sonuçlar artık tek karar noktasında toplanır.

Graph topolojisini derleme

Node’lar ve edge’ler aynı ana state sözleşmesi üzerinde birleştirilir; conditional edge, Send tabanlı map geçişini bağlar.

Graph topolojisini derleme
from IPython.display import Image
from langgraph.graph import END, StateGraph, START

# Construct the graph: here we put everything together to construct our graph
graph = StateGraph(OverallState)
graph.add_node("generate_topics", generate_topics)
graph.add_node("generate_joke", generate_joke)
graph.add_node("best_joke", best_joke)
graph.add_edge(START, "generate_topics")
graph.add_conditional_edges(
    "generate_topics",
    continue_to_jokes,
    ["generate_joke"],
)
graph.add_edge("generate_joke", "best_joke")
graph.add_edge("best_joke", END)

# Compile the graph
app = graph.compile()
Image(app.get_graph().draw_mermaid_png())

LangGraph açısından önemi

add_conditional_edges ile continue_to_jokes fonksiyonu generate_topics sonrasına yerleştirilir. Böylece alt konu sayısına göre dinamik fan-out oluşur.

Dikkat edilmesi gereken nokta

compile edilmeden graph çalıştırılamaz. Bu adım builder tanımını yürütülebilir app nesnesine dönüştürür.

Graph görseli

Çıktı Yorumu

Görsel çıktı, START → generate_topics sonrasında koşullu geçişle generate_joke node’una gidildiğini ve bu map adımlarının best_joke node’unda toplandığını gösterir.

Graph çalışmasını stream ile izleme

Son kod bloğu graph’ı örnek bir konu ile çalıştırır ve her node update’ini görünür hale getirir.

Graph çalışmasını stream ile izleme

for s in app.stream({"topic": "animals"}):
    print(s)

LangGraph açısından önemi

app.stream, yürütme sırasında hangi node’un hangi state alanını yazdığını sırayla gösterir. Bu, map dallarını ve reduce sonucunu okumayı kolaylaştırır.

Dikkat edilmesi gereken nokta

Çıktıdaki generate_joke kayıtları ayrı ayrı görünür; bunlar aynı node’un farklı subject değerleriyle çalıştırılmış map dallarıdır.

Çıktı Yorumu

İlk satırda subjects listesi üretilir. Sonraki üç satırda map fazındaki generate_joke update’leri gelir. Son satırda reduce fazı best_selected_joke alanını yazar.

Çıktıların Yorumlanması

Graph görselinde dikkat edilmesi gereken nokta, generate_topics sonrasındaki koşullu geçiştir. Bu geçiş, tek bir sabit edge gibi düşünülmemelidir; continue_to_jokes fonksiyonu her subject için ayrı Send ürettiği için generate_joke node’u çalışma anında birden fazla kez çağrılır.

Streaming çıktısında ilk update subjects listesini gösterir. Sonraki update’ler aynı node adı altında üç ayrı jokes yazımıdır. Bu tekrar, graph’ın yanlışlıkla aynı işi üç kez yapması değil, map fazının beklenen davranışıdır. Son update ise reduce fazındaki best_selected_joke alanını gösterir.

Okuma Rehberi

Stream çıktısını okurken node adını, yazılan state alanını ve alanın tipini birlikte incelemek gerekir. generate_joke update’lerinde değer liste olarak gelir; bu, reducer’ın liste birleştirme davranışı için önemlidir.

Graph Akışı

Gerçek koddan çıkarılan graph akışı şu sıradadır:

STARTGraph kullanıcı topic değeriyle başlar.
generate_topicssubjects listesini üretir.
generate_jokeSend ile her subject için ayrı çağrılır.
best_joke → ENDReducer’da biriken şakalardan en iyisini seçer.

Metinsel olarak akış START → generate_topics → Send(generate_joke × N) → best_joke → END biçiminde okunabilir. Buradaki N, subjects listesinin çalışma anındaki uzunluğudur.

State’in Evrimi

Başlangıç{"topic": "animals"} inputu graph’a verilir. Henüz subjects, jokes veya best_selected_joke yoktur.
Alt konu üretimigenerate_topics, subjects alanına ["mammals", "reptiles", "birds"] benzeri bir liste yazar.
Map yazımlarıHer generate_joke çağrısı {"jokes": ["..."]} biçiminde tek elemanlı liste döndürür.
Reducer birleşimioperator.add, paralel jokes listelerini tek bir jokes listesinde toplar.
Reduce sonucubest_joke, best_selected_joke alanını seçilen şaka metniyle günceller.
Nihai stateGraph bittiğinde topic, subjects, tüm jokes ve seçilen en iyi şaka aynı state sözleşmesinde bulunur.

Agent / Tool Etkileşimi

Bu derste tam bir agent-tool döngüsü kurulmaz. Odak, state yönetimi, structured output, Send ile dinamik fan-out ve reducer ile sonuç birleştirmedir.

Kullanıcı girdisiGenel konu topic olarak graph’a verilir.
Model çağrılarıModel önce alt konuları, sonra her alt konu için şakayı, son olarak en iyi şaka indeksini üretir.
ToolNode yokBu akışta ToolNode veya harici araç çalıştırma node’u kullanılmaz; structured output şemaları model cevabını biçimlendirir.

Yaygın Hatalar

  • State’i local değişken sanmak: OverallState, node’lar arası sözleşmedir; tek fonksiyonun iç değişkeni değildir.
  • Send listesini normal Python çıktısı sanmak: Bu liste conditional edge tarafından graph çağrılarına dönüştürülür.
  • Reducer olmadan paralel append beklemek: jokes alanı operator.add ile tanımlanmadığında paralel update davranışı güvenli biçimde birleşmez.
  • Mapped node’un ana state’i almak zorunda olduğunu düşünmek: generate_joke, kendi JokeState sözleşmesiyle çalışır.
  • Structured output’u sadece biçimsel kolaylık sanmak: Subjects, Joke ve BestJoke şemaları node dönüşlerinin state update’ine uygun olmasını sağlar.
  • Graph compile edilmeden çalıştırmaya çalışmak: Builder tanımı graph.compile() ile yürütülebilir app nesnesine dönüştürülmelidir.
  • Stream çıktısındaki tekrarları hata sanmak: Birden çok generate_joke update’i map fazının doğal sonucudur.
  • Reduce fazını model özetleme adımıyla karıştırmak: Bu örnekte reduce, tüm şakalardan indeks tabanlı seçim yapar; yeni bir özet üretmek zorunda değildir.
  • API anahtarını kod içine yazmak: Anahtarlar ortam değişkeni üzerinden alınır; ders kodu gizli değerleri sabitlemez.

Son Çıkarımlar

  1. Map-reduce, LangGraph’ta veriyle belirlenen paralel node çağrılarını ve sonrasında tekleştirme adımını modellemek için kullanışlıdır.
  2. Send, hedef node adını ve o node’a gönderilecek state parçasını birlikte taşır.
  3. Mapped node’un state sözleşmesi, ana graph state sözleşmesinden bağımsız tasarlanabilir.
  4. Annotated[list, operator.add], paralel liste update’lerini güvenli biçimde birleştirir.
  5. generate_topics node’u fan-out sayısını doğrudan değil, subjects listesi üzerinden dolaylı olarak belirler.
  6. generate_joke map fazının worker node’udur; aynı node birden fazla farklı inputla çağrılır.
  7. best_joke reduce fazında tüm map sonuçlarını tek karar alanına dönüştürür.
  8. Structured output şemaları, model cevabını state update’ine uygun biçimde okumayı kolaylaştırır.
  9. Stream çıktısı, graph’ın hangi node’da hangi state alanını güncellediğini analiz etmek için doğrudan kullanılabilir.
  10. Bu desen, ileride daha karmaşık araştırma veya çok ajanlı iş akışlarında alt görevleri dağıtmak için temel oluşturur.

import getpass
import os


def _set_env(var: str):
    """
    Set an environment variable when it is missing.

        var: Environment variable name.
    """
    if not os.environ.get(var):

_set_env("OPENAI_API_KEY")

_set_env("LANGSMITH_API_KEY")
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_PROJECT"] = "langchain-academy"

from langchain_openai import ChatOpenAI

# Prompts we will use
subjects_prompt = (
    "Generate a list of 3 sub-topics that are all related to this overall "
    "topic: {topic}."
)
joke_prompt = """Generate a joke about {subject}"""
best_joke_prompt = (
    "Below are a bunch of jokes about {topic}. Select the best one! "
    "Return the ID of the best one, starting 0 as the ID for the first joke. "
    "Jokes: \n\n  {jokes}"
)

# LLM
model = ChatOpenAI(model="gpt-4o", temperature=0)

import operator
from typing import Annotated

from pydantic import BaseModel
from typing_extensions import TypedDict


class Subjects(BaseModel):
    """
    Define the Subjects data model.
    """
    subjects: list[str]


class BestJoke(BaseModel):
    """
    Define the BestJoke data model.
    """
    id: int


class OverallState(TypedDict):
    """
    Define the state schema used by the graph.
    """
    topic: str
    subjects: list
    jokes: Annotated[list, operator.add]
    best_selected_joke: str

def generate_topics(state: OverallState):
    """
    Run the generate_topics helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    prompt = subjects_prompt.format(topic=state["topic"])
    response = model.with_structured_output(Subjects).invoke(prompt)
    return {"subjects": response.subjects}

from langgraph.types import Send


def continue_to_jokes(state: OverallState):
    """
    Run the continue_to_jokes helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    return [
        Send("generate_joke", {"subject": s})
        for s in state["subjects"]
    ]

class JokeState(TypedDict):
    """
    Define the state schema used by the graph.
    """
    subject: str


class Joke(BaseModel):
    """
    Define the Joke data model.
    """
    joke: str


def generate_joke(state: JokeState):
    """
    Run the generate_joke helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    prompt = joke_prompt.format(subject=state["subject"])
    response = model.with_structured_output(Joke).invoke(prompt)
    return {"jokes": [response.joke]}

def best_joke(state: OverallState):
    """
    Run the best_joke helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    jokes = "\n\n".join(state["jokes"])
    prompt = best_joke_prompt.format(topic=state["topic"], jokes=jokes)
    response = model.with_structured_output(BestJoke).invoke(prompt)
    return {"best_selected_joke": state["jokes"][response.id]}

from IPython.display import Image
from langgraph.graph import END, StateGraph, START

# Construct the graph: here we put everything together to construct our graph
graph = StateGraph(OverallState)
graph.add_node("generate_topics", generate_topics)
graph.add_node("generate_joke", generate_joke)
graph.add_node("best_joke", best_joke)
graph.add_edge(START, "generate_topics")
graph.add_conditional_edges(
    "generate_topics",
    continue_to_jokes,
    ["generate_joke"],
)
graph.add_edge("generate_joke", "best_joke")
graph.add_edge("best_joke", END)

# Compile the graph
app = graph.compile()
Image(app.get_graph().draw_mermaid_png())

# Call the graph: here we call it to generate a list of jokes
for s in app.stream({"topic": "animals"}):
    print(s)
