LangGraph’ta Paralelleştirme: Fan-out, Fan-in ve Reducer Tasarımı

Bu ders, LangGraph içinde paralel node çalıştırmayı, aynı state anahtarına eşzamanlı yazma problemini, reducer stratejileriyle çözmeyi ve bu yaklaşımı paralel retrieval tabanlı bir answer akışına taşımayı açıklar.

Kapsam ve Bağlam

Paralelleştirme, agent graph tasarımında performans ve modülerlik için merkezi bir araçtır. Ancak fan-out ile aynı adımda birden fazla node aynı state anahtarını güncellediğinde, reducer tanımı yoksa update çakışması oluşur. Bu bölüm önce lineer ve paralel topolojiyi karşılaştırır, ardından reducer ile güvenli state birleştirmeyi adım adım gösterir.

Temel kavram

Fan-out bir node’dan birden fazla dala ayrılmayı, fan-in bu dalların bir birleşim node’unda tekrar toplanmasını ifade eder. Fan-out adımında aynı state kanalına çoklu yazma yapılacaksa reducer zorunludur.

Lineer akışA→B→C→D sıralı ilerler, tek yazan tek adım modelidir.
Fan-outA’dan B ve C’ye aynı adımda paralel çıkış yapılır.
ÇakışmaReducer yoksa aynı key’e çoklu update `InvalidUpdateError` üretir.
ReducerAnnotated reducer çoklu update’i birleştirir.
Fan-inBirleşim node’u tüm paralel dallar bitmeden çalışmaz.

Öğrenme Hedefleri

  • Paralel dallarda reducer yokken neden InvalidUpdateError alındığını açıklamak.
  • Annotated[list, operator.add] ile çoklu state güncellemeyi güvenli biçimde birleştirmek.
  • Fan-in bariyerinin asimetrik dal uzunluklarında nasıl çalıştığını yorumlamak.
  • Özel reducer ile update sırasını uygulama ihtiyacına göre kontrol etmek.
  • Paralel retrieval + answer topolojisini hem local graph hem SDK stream yüzeyinde çalıştırmak.

Kavramsal Analiz

LangGraph runtime’ı aynı süper-adımda gelen çoklu update’leri state şemasındaki reducer kurallarıyla değerlendirir. Reducer yoksa runtime, aynı key için birden fazla aday değer arasında seçim yapamaz ve hataya düşer. Reducer verildiğinde bu değerler tanımlı bir birleştirme fonksiyonuna göre tek bir state değerine indirgenir.

No reducerAynı adımda aynı key için çoklu update geçersizdir.
Append reducerParalel gelen çıktılar listeye eklenerek korunur.
Custom reducerBirleşim sonrası sıralama/filtreleme gibi uygulama kuralları uygulanır.
Fan-in barrierBirleşim node’u tüm önkoşul dallar tamamlandıktan sonra tetiklenir.

Lineer graph kurulumunu tanımlama

A→B→C→D lineer topoloji, paralel akış öncesi temel state overwrite davranışını göstermek için hazırlanır.

Lineer graph kurulumunu tanımlama
from IPython.display import Image, display

from typing import Any, List
from typing_extensions import TypedDict

from langgraph.graph import StateGraph, START, END

class State(TypedDict):
    """
    Define the state schema used by the graph.
    """
    # Note, no reducer function.
    state: List[str]

class ReturnNodeValue:
    """
    Define the ReturnNodeValue data model.
    """
    def __init__(self, node_secret: str):
        """
        Run the __init__ helper.

        Args:
            node_secret: Value passed as node_secret.
        """
        self._value = node_secret

    def __call__(self, state: State) -> Any:
        """
        Run the __call__ helper.

        Args:
            state: Current graph state.

        Returns:
            Value produced for the surrounding example.
        """
        print(f"Adding {self._value} to {state['state']}")
        return {"state": [self._value]}

# Add nodes
builder = StateGraph(State)

# Initialize each node with node_secret
builder.add_node("a", ReturnNodeValue("I'm A"))
builder.add_node("b", ReturnNodeValue("I'm B"))
builder.add_node("c", ReturnNodeValue("I'm C"))
builder.add_node("d", ReturnNodeValue("I'm D"))

# Flow
builder.add_edge(START, "a")
builder.add_edge("a", "b")
builder.add_edge("b", "c")
builder.add_edge("c", "d")
builder.add_edge("d", END)
graph = builder.compile()

display(Image(graph.get_graph().draw_mermaid_png()))

Özel sıralama reducer’ı tanımlama

Varsayılan güncelleme sırası yerine özel sıralama davranışı veren reducer tanımlanır.

Özel sıralama reducer’ı tanımlama
def sorting_reducer(left, right):
    """ Combines and sorts the values in a list"""
    if not isinstance(left, list):
        left = [left]

    if not isinstance(right, list):
        right = [right]

    return sorted(left + right, reverse=False)

class State(TypedDict):
    """
    Define the state schema used by the graph.
    """
    # sorting_reducer will sort the values in state
    state: Annotated[list, sorting_reducer]

# Add nodes
builder = StateGraph(State)

# Initialize each node with node_secret
builder.add_node("a", ReturnNodeValue("I'm A"))
builder.add_node("b", ReturnNodeValue("I'm B"))
builder.add_node("b2", ReturnNodeValue("I'm B2"))
builder.add_node("c", ReturnNodeValue("I'm C"))
builder.add_node("d", ReturnNodeValue("I'm D"))

# Flow
builder.add_edge(START, "a")
builder.add_edge("a", "b")
builder.add_edge("a", "c")
builder.add_edge("b", "b2")
builder.add_edge(["b2", "c"], "d")
builder.add_edge("d", END)
graph = builder.compile()

İki paralel retrieval + answer graph’ı

`search_web` ve `search_wikipedia` paralel çalışıp `context` alanında birleşir; sonra `generate_answer` node’u cevap üretir.

İki paralel retrieval + answer graph’ı
from langchain_core.messages import HumanMessage, SystemMessage

from langchain_community.document_loaders import WikipediaLoader
from langchain_tavily import TavilySearch  # updated since filming

def search_web(state):

    """ Retrieve docs from web search """

    # Search
    tavily_search = TavilySearch(max_results=3)
    data = tavily_search.invoke({"query": state['question']})
    search_docs = data.get("results", data)

     # Format
    formatted_search_docs = "\n\n---\n\n".join(
        [
            f'<Document href="{doc["url"]}">\n{doc["content"]}\n</Document>'
            for doc in search_docs
        ]
    )

    return {"context": [formatted_search_docs]}

def search_wikipedia(state):

    """ Retrieve docs from wikipedia """

    # Search
    search_docs = WikipediaLoader(query=state['question'],
                                  load_max_docs=2).load()

     # Format
    formatted_search_docs = "\n\n---\n\n".join(
        [
            f'<Document source="{doc.metadata["source"]}" page="{doc.metadata.get("page", "")}">\n{doc.page_content}\n</Document>'
            for doc in search_docs
        ]
    )

    return {"context": [formatted_search_docs]}

def generate_answer(state):

    """ Node to answer a question """

    # Get state
    context = state["context"]
    question = state["question"]

    # Template

        [
            SystemMessage(content=answer_instructions),
            HumanMessage(content="Answer the question."),
        ]
    )

    # Append it to state
    return {"answer": answer}

API Boyutu

Aynı paralel graph semantiği SDK tarafında da korunur. Thread açılıp client.runs.stream(..., stream_mode="values") ile event akışı izlendiğinde, state içinde answer alanı dolduğu anda final metin alınır. Bu, notebook deneyimi ile servisleşmiş çalışma arasında davranış eşdeğerliği sağlar.

Uygulama notu

Üretim akışında paralel node’lar yalnızca performans değil, hata yalıtımı ve kaynak çeşitliliği için de tasarlanmalıdır. Reducer stratejisi state modelinin ayrılmaz bir parçası olarak ele alınmalıdır.

Yaygın Hatalar ve Kontroller

  • Paralel node’ların aynı key’e yazdığı halde reducer tanımlamamak.
  • Fan-in node’unun tüm upstream dalları beklediğini göz ardı edip erken sonuç beklemek.
  • Update sırasını iş kuralı olarak kullanıp buna uygun özel reducer yazmamak.
  • SDK çalıştırmasında yanlış assistant_id kullanmak.
  • Retrieval context formatını düzensiz bırakıp answer prompt’unu belirsiz hale getirmek.

def sorting_reducer(left, right):
    """ Combines and sorts the values in a list"""
    if not isinstance(left, list):

    if not isinstance(right, list):
        right = [right]

    return sorted(left + right, reverse=False)

def search_web(state):

    """ Retrieve docs from web search """

    # Search
    tavily_search = TavilySearch(max_results=3)
    data = tavily_search.invoke({"query": state['question']})
    search_docs = data.get("results", data)

     # Format
    formatted_search_docs = "\n\n---\n\n".join(
        [
            f'<Document href="{doc["url"]}">\n{doc["content"]}\n</Document>'
            for doc in search_docs
        ]
    )

    return {"context": [formatted_search_docs]}

def search_wikipedia(state):

    """ Retrieve docs from wikipedia """

    # Search
    search_docs = WikipediaLoader(query=state['question'],
                                  load_max_docs=2).load()

     # Format
    formatted_search_docs = "\n\n---\n\n".join(
        [
            f'<Document source="{doc.metadata["source"]}" page="{doc.metadata.get("page", "")}">\n{doc.page_content}\n</Document>'
            for doc in search_docs
        ]
    )

    return {"context": [formatted_search_docs]}

        [

            HumanMessage(content="Answer the question."),
