LangGraph ile Çok Ajanlı Araştırma Asistanı

Bu ders, insan geri bildirimi, paralel bilgi toplama, alt graph yapısı ve MapReduce deseniyle özelleştirilebilir bir araştırma otomasyonunun nasıl kurulacağını inceler.

Kapsam ve Bağlam

Bu bölümde amaç, araştırma otomasyonu için yalnızca tek bir LLM çağrısı yapmak yerine planlama, kaynak toplama, insan geri bildirimi ve rapor sentezini graph tabanlı bir yürütme olarak modellemektir. Ders, bellek, denetlenebilirlik ve human-in-the-loop kavramlarını daha gerçekçi bir çok ajanlı araştırma sisteminde bir araya getirir.

Bu Dersin Ana Tezi

Kaliteli araştırma çıktısı, rastgele üretilmiş tek cevaplardan çok; kapsamı belirlenmiş analist personları, kaynakla desteklenen uzman yanıtları, paralel görüşmeler ve kontrollü bir reduce aşamasıyla elde edilir.

Öğrenme Hedefleri

  • StateGraph içinde planlama, görüşme ve rapor sentezi adımlarının nasıl ayrıştırıldığını açıklayabilecek.
  • interrupt_before, get_state ve update_state kullanarak human-in-the-loop akışının nasıl kurulduğunu yorumlayabilecek.
  • Pydantic structured output ile analist persona üretiminin neden serbest metinden daha denetlenebilir olduğunu açıklayabilecek.
  • MessagesState ve reducer tanımının paralel kaynak toplama sırasında nasıl state birleştirmesi yaptığını gösterebilecek.
  • Send API'sinin MapReduce desenindeki map adımını nasıl temsil ettiğini kod üzerinden ayırt edebilecek.
  • Alt graph kapsülleme yaklaşımının üst graph state'ini neden sade tuttuğunu açıklayabilecek.
  • stream_mode="values" ile stream_mode="updates" arasındaki gözlem farkını çıktılar üzerinden yorumlayabilecek.

Ön Koşullar

  • Python fonksiyonları, dictionary/list yapıları ve type hint okuryazarlığı.
  • TypedDict, Annotated, Literal ve Pydantic BaseModel kullanımına temel aşinalık.
  • LLM mesaj rolleri, chat model çağrısı ve environment variable mantığı.
  • LangGraph'ta node, edge, state, checkpoint ve graph compile kavramları.
  • Web araması ve retrieval-augmented generation yaklaşımına temel sezgi.

Alt Graph Neden Kullanılır?

Görüşme akışı kendi mesaj geçmişine, kaynak bağlamına ve bölüm yazımına sahiptir. Bu ayrıntıları üst graph state'ine taşımak yerine alt graph içinde kapsüllemek, üst graph'ı yalnızca planlama ve rapor sentezi düzeyinde tutar.

MapReduce Sezgisi

Her analist için aynı görüşme alt graph'ı çalıştırılır. Bu map fazıdır. Her görüşme bir rapor bölümü üretir. Bu bölümler sections alanında birikir ve nihai rapor yazımı reduce fazını oluşturur.

Analist Şemalarını ve State Sözleşmesini Kurma

Analist persona alanları Pydantic modelleriyle, analist üretim graph'ının taşıyacağı state ise TypedDict ile tanımlanır.

Analist Şemalarını ve State Sözleşmesini Kurma 
from typing import List
from typing_extensions import TypedDict
from pydantic import BaseModel, Field

class Analyst(BaseModel):
    """
    Define the Analyst data model.
    """
    affiliation: str = Field(
        description="Primary affiliation of the analyst.",
    )
    name: str = Field(
        description="Name of the analyst."
    )
    role: str = Field(
        description="Role of the analyst in the context of the topic.",
    )
    description: str = Field(
        description="Description of the analyst focus, concerns, and motives.",
    )
    @property
    def persona(self) -> str:
        """
        Run the persona helper.

        Returns:
            Value produced for the surrounding example.
        """
        return f"Name: {self.name}\nRole: {self.role}\nAffiliation: {self.affiliation}\nDescription: {self.description}\n"

class Perspectives(BaseModel):
    """
    Define the Perspectives data model.
    """
    analysts: List[Analyst] = Field(
        description="Comprehensive list of analysts with their roles and affiliations.",
    )

class GenerateAnalystsState(TypedDict):
    """
    Define the state schema used by the graph.
    """
    topic: str # Research topic
    max_analysts: int # Number of analysts
    human_analyst_feedback: str # Human feedback
    analysts: List[Analyst] # Analyst asking questions

Analist Üretim Graph'ını Derleme

Konu ve olası insan geri bildirimi kullanılarak analist personlarını üreten, ardından insan kontrol noktasında duran ilk graph kurulur.

Analist Üretim Graph'ını Derleme 
from IPython.display import Image, display
from langgraph.graph import START, END, StateGraph
from langgraph.checkpoint.memory import MemorySaver
from langchain_core.messages import AIMessage, HumanMessage, SystemMessage

analyst_instructions="""You are tasked with creating a set of AI analyst personas. Follow these instructions carefully:

1. First, review the research topic:
{topic}

2. Examine any editorial feedback that has been optionally provided to guide creation of the analysts:

{human_analyst_feedback}

3. Determine the most interesting themes based upon documents and / or feedback above.

4. Pick the top {max_analysts} themes.

5. Assign one analyst to each theme."""

def create_analysts(state: GenerateAnalystsState):

    """ Create analysts """

    topic = state['topic']
    max_analysts = state['max_analysts']
    human_analyst_feedback = state.get('human_analyst_feedback', '')

    # Enforce structured output
    structured_llm = llm.with_structured_output(Perspectives)

    # System message
    system_message = analyst_instructions.format(
        topic=topic,
        human_analyst_feedback=human_analyst_feedback,
        max_analysts=max_analysts,
    )

    # Generate question
    analysts = structured_llm.invoke(
        [SystemMessage(content=system_message)]
        + [HumanMessage(content="Generate the set of analysts.")]
    )

    # Write the list of analysis to state
    return {"analysts": analysts.analysts}

def human_feedback(state: GenerateAnalystsState):
    """ No-op node that should be interrupted on """
    pass

def should_continue(state: GenerateAnalystsState):
    """ Return the next node to execute """

    # Check if human feedback
    human_analyst_feedback = state.get('human_analyst_feedback', None)
    if human_analyst_feedback:
        return "create_analysts"

    # Otherwise end
    return END

# Add nodes and edges
builder = StateGraph(GenerateAnalystsState)
builder.add_node("create_analysts", create_analysts)
builder.add_node("human_feedback", human_feedback)
builder.add_edge(START, "create_analysts")
builder.add_edge("create_analysts", "human_feedback")
builder.add_conditional_edges("human_feedback", should_continue, ["create_analysts", END])

# Compile
memory = MemorySaver()
graph = builder.compile(interrupt_before=['human_feedback'], checkpointer=memory)

# View
display(Image(graph.get_graph(xray=1).draw_mermaid_png()))

def generate_answer(state: InterviewState):

    """ Node to answer a question """

    # Get state
    analyst = state["analyst"]
    messages = state["messages"]
    context = state["context"]

    # Answer question
    system_message = answer_instructions.format(
        goals=analyst.persona,
        context=context,
    )
    answer = llm.invoke([SystemMessage(content=system_message)]+messages)

    # Name the message as coming from the expert
    answer.name = "expert"

    # Append it to state
    return {"messages": [answer]}

def save_interview(state: InterviewState):

    """ Save interviews """

    # Get messages
    messages = state["messages"]

    # Convert interview to a string
    interview = get_buffer_string(messages)

    # Save to interviews key
    return {"interview": interview}

def route_messages(
    state: InterviewState,
    name: str = "expert",
):

    """ Route between question and answer """

    # Get messages
    messages = state["messages"]
    max_num_turns = state.get('max_num_turns', 2)

    # Check the number of expert answers
    num_responses = len(
        [m for m in messages if isinstance(m, AIMessage) and m.name == name]
    )

    # End if expert has answered more than the max turns
    if num_responses >= max_num_turns:
        return 'save_interview'

    # This router is run after each question - answer pair
    # Get the last question asked to check if it signals the end of discussion
    last_question = messages[-2]

    if "Thank you so much for your help" in last_question.content:
        return 'save_interview'
    return "ask_question"

def write_section(state: InterviewState):

    # Summarize the sections into a final report

    instructions = intro_conclusion_instructions.format(topic=topic, formatted_str_sections=formatted_str_sections)
    intro = llm.invoke(
        [instructions]
        + [HumanMessage(content="Write the report introduction")]
    )
    return {"introduction": intro.content}

def write_conclusion(state: ResearchGraphState):
    """
    Run the write_conclusion helper.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    # Full set of sections
    sections = state["sections"]
    topic = state["topic"]

    # Concat all sections together
    formatted_str_sections = "\n\n".join([f"{section}" for section in sections])

    # Summarize the sections into a final report

    instructions = intro_conclusion_instructions.format(topic=topic, formatted_str_sections=formatted_str_sections)
    conclusion = llm.invoke(
        [instructions]
        + [HumanMessage(content="Write the report conclusion")]
    )
    return {"conclusion": conclusion.content}

def finalize_report(state: ResearchGraphState):
    """ The is the "reduce" step where we gather all the sections, combine them, and reflect on them to write the intro/conclusion """
    # Save full final report
    content = state["content"]
    if content.startswith("## Insights"):
        content = content.strip("## Insights")
    if "## Sources" in content:
        try:
            content, sources = content.split("\n## Sources\n")
        except:
            sources = None
    else:
        sources = None

    final_report = (
        state["introduction"]
        + "\n\n---\n\n"
        + content
        + "\n\n---\n\n"
        + state["conclusion"]
    )
    if sources is not None:
        final_report += "\n\n## Sources\n" + sources
    return {"final_report": final_report}

def create_analysts(state: GenerateAnalystsState):

        [SystemMessage(content=system_message)]

def generate_answer(state: InterviewState):

def save_interview(state: InterviewState):

def route_messages(
    state: InterviewState,
    name: str = "expert",
):

    """ Route between question and answer """

    # Get messages
    messages = state["messages"]
    max_num_turns = state.get('max_num_turns', 2)

    # Check the number of expert answers
    num_responses = len(
        [m for m in messages if isinstance(m, AIMessage) and m.name == name]
    )

    # End if expert has answered more than the max turns
    if num_responses >= max_num_turns:
        return 'save_interview'

    # This router is run after each question - answer pair
    # Get the last question asked to check if it signals the end of discussion
    last_question = messages[-2]

    if "Thank you so much for your help" in last_question.content:
        return 'save_interview'
    return "ask_question"
