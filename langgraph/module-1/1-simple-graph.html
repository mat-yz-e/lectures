LangGraph’ta En Basit Graph: State, Node ve Koşullu Edge

Bu bölüm, LangGraph’ın temel yapı taşlarını küçük ve denetlenebilir bir graph üzerinden açıklar: state, node, edge, koşullu yönlendirme, derleme ve invoke akışı.

Kapsam ve Bağlam

Bu ders, LangGraph’ın temel çalışma modelini en küçük anlamlı örnek üzerinden kurar. Amaç, agent veya tool kullanmadan önce graph fikrinin hangi parçalardan oluştuğunu teknik olarak görünür hale getirmektir: state, node, edge, koşullu yönlendirme, derleme ve çalıştırma.

Örnekte graph tek bir metin alanını taşır. İlk node bu metne ortak bir ifade ekler; ardından koşullu edge rastgele olarak iki yoldan birini seçer. Böylece öğrenci, graph’ın sıradan Python fonksiyonlarını nasıl düzenli bir yürütme akışına dönüştürdüğünü açık biçimde izler.

Bu Dersin Ana Tezi

LangGraph’ta graph, yalnızca fonksiyonları yan yana koymak değildir. State’in hangi biçimde taşınacağı, node’ların state’i nasıl güncelleyeceği ve edge’lerin hangi sırayı veya koşulu uygulayacağı birlikte tanımlanır.

Öğrenme Hedefleri

  • TypedDict ile basit bir LangGraph state şeması tanımlayabilmek.
  • Node fonksiyonlarının state’i nasıl okuyup yeni state değeri döndürdüğünü açıklayabilmek.
  • Normal edge ile conditional edge arasındaki farkı teknik olarak ayırt edebilmek.
  • START ve END özel düğümlerinin graph sınırlarını nasıl belirlediğini açıklayabilmek.
  • StateGraph, add_node, add_edge, add_conditional_edges ve compile akışını sırayla uygulayabilmek.
  • invoke çağrısının başlangıç state’i alıp nihai state döndürme davranışını yorumlayabilmek.
  • Rastgele yönlendirme içeren örnekte çıktının neden farklı çalıştırmalarda değişebileceğini açıklayabilmek.

Ön Koşullar

Bu dersi takip etmek için Python fonksiyonları, sözlük erişimi, string birleştirme, type hint mantığı ve basit paket kurulumu bilinmelidir. TypedDict kavramını daha önce kullanmamış olmak sorun değildir; bu derste yalnızca state anahtarlarının beklenen biçimini göstermek için kullanılır.

LangGraph açısından temel sezgi şudur: graph içindeki her işlem adımı Python fonksiyonu olabilir; ancak bu fonksiyonlar rastgele sırayla değil, açıkça tanımlanmış edge ilişkileriyle çalıştırılır.

Büyük Resim

LangGraph’ın temel fikri, uygulama mantığını düğümler ve geçişler halinde düzenlemektir. Bu derste model çağrısı veya tool kullanımı yoktur; bilinçli olarak daha küçük bir örnek seçilir. Böylece graph’ın yapısal parçaları, LLM ayrıntılarıyla karışmadan görülebilir.

State, graph’ın belleği gibi düşünülebilir; ancak bu örnekte kalıcı bellek değil, adımlar arasında taşınan geçici çalışma verisidir. Node’lar bu state’i okur ve yeni değer döndürür. Edge’ler ise hangi node’un ne zaman çalışacağını belirler.

Ana Anlatım

State: Paylaşılan Veri Sözleşmesi

State, graph içindeki adımların ortak dilidir. Bu derste state yalnızca graph_state adlı bir string alanı taşır. Bu sadelik pedagojiktir: karmaşık veri şemaları olmadan, node’ların state’i nasıl alıp güncellediği izlenebilir.

Kritik Ayrım

State bir local değişken değildir. Node fonksiyonuna giren ve node çıktısıyla güncellenen graph verisidir. LangGraph, node’lar arasında bu verinin nasıl taşınacağını graph tanımıyla ilişkilendirir.

Node: State’i Güncelleyen Fonksiyon

Node’lar sıradan Python fonksiyonlarıdır; fakat LangGraph içinde belirli bir sözleşmeye göre çalışırlar. State’i argüman olarak alırlar ve state alanlarını güncelleyen bir sözlük döndürürler. Varsayılan davranışta aynı anahtar için dönen yeni değer önceki değerin üzerine yazılır.

Edge: Sıra ve Koşul Mantığı

Normal edge, her çalıştırmada aynı geçişi uygular. Örnekte START her zaman node_1 düğümüne gider. Conditional edge ise bir karar fonksiyonuna dayanır. decide_mood, node_2 veya node_3 adını döndürerek graph’ın hangi yola gideceğini belirler.

Öğrencinin Sorması Gereken Soru

Bir karar fonksiyonu state’i güncellemeli mi, yoksa yalnızca sonraki node adını mı döndürmeli? Bu derste cevap nettir: koşullu edge fonksiyonu yönlendirme yapar; state güncellemesini node fonksiyonları yapar.

Compile ve Runnable Arayüzü

compile çağrısı graph tanımını çalıştırılabilir hale getirir. Derlenmiş graph, LangChain ekosistemindeki runnable arayüzünü uygular. Bu nedenle invoke ile başlangıç state’i verilip tüm graph senkron olarak çalıştırılabilir.

Kod Yürüyüşü

Kod yürüyüşü, graph’ın parçalarını doğal sırayla kurar: önce state şeması, sonra node’lar, ardından koşullu karar fonksiyonu, graph inşası ve son olarak çalıştırma.

Koşullu edge karar fonksiyonunu tanımlama

Bu blok, graph’ın `node_1` sonrasında hangi düğüme gideceğini belirleyen yönlendirme fonksiyonunu tanımlar. Örnek karar rastgele verilir; gerçek uygulamalarda bu karar çoğunlukla state içeriğine dayanır.

Koşullu edge karar fonksiyonunu tanımlama
import random
from typing import Literal

def decide_mood(state) -> Literal["node_2", "node_3"]:
    """
    Run the decide_mood graph node.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """

    # Often, we will use state to decide on the next node to visit
    user_input = state['graph_state']

    # Here, let's just do a 50 / 50 split between nodes 2, 3
    if random.random() < 0.5:

        # 50% of the time, we return Node 2
        return "node_2"

    # 50% of the time, we return Node 3
    return "node_3"

LangGraph açısından önemi

`decide_mood`, state’i güncellemez; yalnızca bir sonraki node adını döndürür. Bu ayrım, node fonksiyonu ile conditional edge fonksiyonunun görevlerini ayırmak için kritiktir.

Graph yapısını kurma ve derleme

Bu blok, tanımlanan state şemasını, node fonksiyonlarını ve edge ilişkilerini `StateGraph` içinde bir araya getirir. Ardından graph derlenir ve görsel olarak gösterilir.

Graph yapısını kurma ve derleme
from IPython.display import Image, display
from langgraph.graph import StateGraph, START, END

# Build graph
builder = StateGraph(State)
builder.add_node("node_1", node_1)
builder.add_node("node_2", node_2)
builder.add_node("node_3", node_3)

# Logic
builder.add_edge(START, "node_1")
builder.add_conditional_edges("node_1", decide_mood)
builder.add_edge("node_2", END)
builder.add_edge("node_3", END)

# Add
graph = builder.compile()

# View
display(Image(graph.get_graph().draw_mermaid_png()))

LangGraph açısından önemi

Çıktıların Yorumlanması

Graph görseli, başlangıçtan ilk node’a normal edge ile gidildiğini ve ilk node’dan sonra conditional edge ile iki olası yola ayrıldığını gösterir. Dotted veya dallanan geçişin anlamı, karar fonksiyonunun tek bir sabit hedef yerine olası hedeflerden birini seçmesidir.

Çalıştırma çıktısında önce node izleri yazdırılır. Bu izler graph’ın hangi düğümleri gerçekten çalıştırdığını gösterir. Ardından dönen sözlük, nihai state değeridir. Karar fonksiyonu rastgelelik kullandığı için örneğin başka bir çalıştırmada happy! son eki de görülebilir.

Agent / Tool Etkileşimi

Bu derste agent döngüsü veya tool çağrısı kurulmaz. Bunun nedeni, önce graph kontrol akışını yalın biçimde görmektir. İlerleyen agent tasarımlarında benzer node ve edge yapıları, model çağrıları ve tool sonuçlarıyla birlikte kullanılabilir.

Bu dersteki yapı: State, node ve edge ilişkileriyle deterministik veya koşullu akış kurulur.
Agent sistemlerine bağlantı: Daha sonra bir node model çağırabilir, başka bir node tool sonucunu state’e yazabilir ve conditional edge hangi adımın sırada olduğunu seçebilir.

Yaygın Hatalar

  • State’i yalnızca node içindeki local değişken sanmak.
  • Node fonksiyonunun bir sonraki node’u seçmesi gerektiğini düşünmek; bu örnekte seçim conditional edge fonksiyonuna aittir.
  • add_edge ile add_conditional_edges farkını karıştırmak.
  • START ve END düğümlerini normal kullanıcı tanımlı node gibi ele almak.
  • compile çağrısından önce graph’ı invoke etmeye çalışmak.
  • Varsayılan state güncellemesinin aynı anahtarda eski değerin üzerine yazdığını gözden kaçırmak.
  • Rastgele karar fonksiyonu nedeniyle farklı çalıştırmalarda farklı çıktı alınabileceğini unutmak.
  • Graph görselini çalışma garantisi sanmak; asıl çalışma davranışı derlenmiş graph ve state geçişleriyle doğrulanır.

Son Çıkarımlar

  1. LangGraph graph’ı, state şeması, node fonksiyonları ve edge ilişkilerinden oluşur.
  2. State, node ve edge fonksiyonlarının ortak veri sözleşmesidir.
  3. Node’lar Python fonksiyonlarıdır; state alır ve state güncellemesi döndürür.
  4. Varsayılan davranışta aynı state anahtarına dönen yeni değer eski değerin üzerine yazılır.
  5. Normal edge, her çalıştırmada aynı hedefe geçiş sağlar.
  6. Conditional edge, karar fonksiyonunun döndürdüğü node adına göre yönlendirme yapar.
  7. START graph’ın girişini, END terminal noktasını temsil eder.
  8. compile, graph tanımını çalıştırılabilir nesneye dönüştürür.
  9. Derlenmiş graph, invoke ile başlangıç state’inden nihai state’e kadar çalıştırılabilir.
  10. Bu basit örnek, daha karmaşık agent, router ve tool akışlarının temel kontrol modelini hazırlar.
