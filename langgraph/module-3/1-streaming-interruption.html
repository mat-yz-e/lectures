LangGraph’ta Streaming: State, Token ve API Olaylarını İzleme

Bu ders, hafızalı bir LangGraph sohbet graph’ında state güncellemelerini, tam state değerlerini, chat model tokenlarını ve API tabanlı mesaj event’lerini Jupyter-stil bir akış içinde inceler.

Kapsam ve Bağlam

Bu ders, hafızalı bir LangGraph sohbet graph’ı çalışırken ortaya çıkan ara durumları ve model tokenlarını nasıl izleyebileceğimizi inceler. Odak noktası, graph tamamlandıktan sonra yalnızca nihai sonucu almak değil, yürütme devam ederken state güncellemelerini, tam state değerlerini, chat model event’lerini ve LangGraph API üzerinden mesaj akışını gözlemlemektir.

Bu Dersin Ana Tezi

Streaming, LangGraph uygulamalarında yalnızca kullanıcı deneyimini hızlandıran bir çıktı tekniği değildir; aynı zamanda graph state’inin, node yürütmesinin, LLM token üretiminin ve tool çağrılarının hangi sırayla oluştuğunu görünür kılan bir denetim mekanizmasıdır.

Öğrenme Hedefleri

  • stream_mode="updates" ile node bazlı state güncellemelerini yorumlayabilecek.
  • stream_mode="values" ile graph’ın birikimli state görünümünü ayırt edebilecek.
  • graph.astream_events(...) çıktısındaki event, name, data ve metadata alanlarının rolünü açıklayabilecek.
  • metadata.langgraph_node alanını kullanarak belirli bir node’dan gelen token stream’ini filtreleyebilecek.
  • AIMessageChunk içinden yalnızca kullanıcıya gösterilecek metin parçasını seçebilecek.
  • LangGraph SDK ile API tabanlı values ve messages stream modlarını karşılaştırabilecek.
  • Tool call argümanlarının stream sırasında kademeli oluşabileceğini ve bunun arayüz tasarımındaki sonucunu açıklayabilecek.

Ön Koşullar

  • Python fonksiyonları, dictionary/list yapıları ve type hint okuma becerisi.
  • async for ve asenkron iterator mantığına temel düzeyde aşinalık.
  • LangChain mesaj tipleri: HumanMessage, AIMessage, SystemMessage, RemoveMessage.
  • LangGraph kavramları: StateGraph, node, edge, START, END, checkpointer ve state.
  • LLM çağrılarında ortam değişkeni ve API anahtarı mantığı.
  • Yerel LangGraph API/Studio sunucusu kullanılıyorsa http://127.0.0.1:2024 adresinde çalışan geliştirme sunucusu.

Büyük Resim

Streaming’i anlamak için üç katmanı ayırmak gerekir: graph state’i, LLM tokenları ve API event kabuğu. State streaming graph node’larının state’i nasıl değiştirdiğini gösterir. Token streaming, bir node içindeki chat modelinin cevabı nasıl parça parça ürettiğini gösterir. API streaming ise aynı fikirleri sunucu/SDK hattında StreamPart ve mesaj event’leri olarak taşır.

Ana Anlatım

State streaming ile token streaming arasındaki ayrım

stream_mode="updates" ve stream_mode="values" graph state’ine bakar. Birincisi yalnızca node’un ürettiği güncellemeyi, ikincisi ise node sonrasındaki tam state’i döndürür. Buna karşılık astream_events, graph içindeki runnable olaylarını dinler; bu olayların içinde chat model tokenları da bulunur.

Streaming neden insan müdahalesine zemin hazırlar?

İnsan müdahalesi içeren graph’larda kullanıcı çoğu zaman graph’ın hangi noktada olduğunu, hangi node’un çalıştığını veya modelin ne üretmeye başladığını görmek ister. Bu derste doğrudan interrupt API’si kurulmaz; ancak streaming, sonraki insan-etkileşimli graph örneklerinde gerekli gözlem altyapısını hazırlar.

API tarafında mesaj odaklı stream

Yerel graph nesnesiyle stream almak ile LangGraph SDK üzerinden stream almak aynı kavramsal temele dayanır; ancak SDK tarafında event’ler StreamPart veya mesaj event adlarıyla gelir. messages modu, özellikle tool çağrıları ve chat cevabı birlikte aktığında daha okunabilir bir stream hattı sağlar.

def call_model(state: State, config: RunnableConfig):
    """
    Run the call_model graph node.

    Args:
        state: Current graph state.
        config: Runtime configuration for the runnable call.

    Returns:
        Value produced for the surrounding example.
    """
    # Get summary if it exists
    summary = state.get("summary", "")

    # If there is summary, then we add it
    if summary:
        # Add summary to system message
        system_message = f"Summary of conversation earlier: {summary}"

        # Append summary to any newer messages
        messages = [SystemMessage(content=system_message)] + state["messages"]
    else:
        messages = state["messages"]

    response = model.invoke(messages, config)
    return {"messages": response}

def summarize_conversation(state: State):
    """
    Run the summarize_conversation helper.

    Args:
        state: Current graph state.
    """
    # First, we get any existing summary
    summary = state.get("summary", "")

    # Create our summarization prompt
    if summary:
        # A summary already exists
        summary_message = (
            f"This is summary of the conversation to date: {summary}\n\n"
            "Extend the summary by taking into account the new messages above:"
        )
    else:
        summary_message = "Create a summary of the conversation above:"

    # Add prompt to our history
    messages = state["messages"] + [HumanMessage(content=summary_message)]
    response = model.invoke(messages)

    # Delete all but the 2 most recent messages
    delete_messages = [RemoveMessage(id=m.id) for m in state["messages"][:-2]]
    return {"summary": response.content, "messages": delete_messages}

def should_continue(state: State) -> Literal["summarize_conversation", END]:
    """Return the next node to execute."""
    messages = state["messages"]

    # If there are more than six messages, then we summarize the conversation
    if len(messages) > 6:
        return "summarize_conversation"

    # Otherwise we can just end
    return END

# Define a new graph
workflow = StateGraph(State)
workflow.add_node("conversation", call_model)
workflow.add_node(summarize_conversation)

# Set the entrypoint as conversation
workflow.add_edge(START, "conversation")
workflow.add_conditional_edges("conversation", should_continue)
workflow.add_edge("summarize_conversation", END)

# Compile
memory = MemorySaver()
graph = workflow.compile(checkpointer=memory)
display(Image(graph.get_graph().draw_mermaid_png()))

thread = await client.threads.create()

def format_tool_calls(tool_calls):
    """
    Format a list of tool calls into a readable string.

    Args:
        tool_calls (list): A list of dictionaries, each representing a tool call.
            Each dictionary should have 'id', 'name', and 'args' keys.

    Returns:
        str: A formatted string of tool calls, or "No tool calls" if the list is empty.
    """
    if tool_calls:
        formatted_calls = []
        for call in tool_calls:
            formatted_calls.append(
                f"Tool Call ID: {call['id']}, "
                f"Function: {call['name']}, "
                f"Arguments: {call['args']}"
            )
        return "\n".join(formatted_calls)
    return "No tool calls"

    # Handle metadata events
    if event.event == "metadata":
        print(f"Metadata: Run ID - {event.data['run_id']}")
        print("-" * 50)

    # Handle partial message events
    elif event.event == "messages/partial":
        for data_item in event.data:
            # Process user messages
            if "role" in data_item and data_item["role"] == "user":
                print(f"Human: {data_item['content']}")
            else:
                # Extract relevant data from the event
                tool_calls = data_item.get("tool_calls", [])
                invalid_tool_calls = data_item.get("invalid_tool_calls", [])
                content = data_item.get("content", "")

                if content:
                    print(f"AI: {content}")

                    print(format_tool_calls(tool_calls))

                if invalid_tool_calls:
                    print("Invalid Tool Calls:")
                    print(format_tool_calls(invalid_tool_calls))

                if response_metadata and response_metadata.get("finish_reason"):
                    print(
                        "Response Metadata: Finish Reason - "
                        f"{response_metadata['finish_reason']}"
                    )
        print("-" * 50)

# Define the logic to call the model
def call_model(state: State, config: RunnableConfig):
    """
    Run the call_model graph node.

    Args:
        state: Current graph state.
        config: Runtime configuration for the runnable call.

    Returns:
        Value produced for the surrounding example.
    """
    # Get summary if it exists
    summary = state.get("summary", "")

    # If there is summary, then we add it
    if summary:
        # Add summary to system message
        system_message = f"Summary of conversation earlier: {summary}"

        # Append summary to any newer messages
        messages = [SystemMessage(content=system_message)] + state["messages"]
    else:
        messages = state["messages"]

    response = model.invoke(messages, config)
    return {"messages": response}


def summarize_conversation(state: State):
    """
    Run the summarize_conversation helper.

    Args:
        state: Current graph state.
    """
    # First, we get any existing summary
    summary = state.get("summary", "")

    # Create our summarization prompt
    if summary:
        # A summary already exists
        summary_message = (
            f"This is summary of the conversation to date: {summary}\n\n"
            "Extend the summary by taking into account the new messages above:"
        )
    else:
        summary_message = "Create a summary of the conversation above:"

    # Add prompt to our history
    messages = state["messages"] + [HumanMessage(content=summary_message)]
    response = model.invoke(messages)

    # Delete all but the 2 most recent messages
    delete_messages = [RemoveMessage(id=m.id) for m in state["messages"][:-2]]
    return {"summary": response.content, "messages": delete_messages}


# Determine whether to end or summarize the conversation
def should_continue(state: State) -> Literal["summarize_conversation", END]:
    """Return the next node to execute."""
    messages = state["messages"]

    # If there are more than six messages, then we summarize the conversation
    if len(messages) > 6:
        return "summarize_conversation"

    # Otherwise we can just end
    return END

def format_tool_calls(tool_calls):
    """
    Format a list of tool calls into a readable string.

    Args:
        tool_calls (list): A list of dictionaries, each representing a tool call.
            Each dictionary should have 'id', 'name', and 'args' keys.

    Returns:
        str: A formatted string of tool calls, or "No tool calls" if the list is empty.
    """
    if tool_calls:
        formatted_calls = []
        for call in tool_calls:
            formatted_calls.append(
                f"Tool Call ID: {call['id']}, "
                f"Function: {call['name']}, "
                f"Arguments: {call['args']}"
            )
        return "\n".join(formatted_calls)
    return "No tool calls"

                invalid_tool_calls = data_item.get("invalid_tool_calls", [])
                content = data_item.get("content", "")

                if content:
                    print(f"AI: {content}")

                if tool_calls:
                    print("Tool Calls:")
                    print(format_tool_calls(tool_calls))

                if invalid_tool_calls:
                    print("Invalid Tool Calls:")
                    print(format_tool_calls(invalid_tool_calls))

                if response_metadata and response_metadata.get("finish_reason"):
                    print(
                        "Response Metadata: Finish Reason - "
                        f"{response_metadata['finish_reason']}"
                    )
