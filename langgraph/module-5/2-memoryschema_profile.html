Profil Şemalarıyla Uzun Süreli Bellek Yönetimi

Bu ders, kullanıcı bilgisini serbest metin yerine yapılandırılmış profil şemalarıyla saklamayı; LangGraph store, structured output ve TrustCall kullanarak belleği oluşturma ve güncelleme akışını açıklar.

Kapsam ve Bağlam

Bu bölümde amaç, bir chatbot’un kullanıcı hakkında öğrendiği bilgileri yalnızca konuşma geçmişinde tutmak yerine, uzun süreli ve şema uyumlu bir profil belleğine dönüştürmektir. Profil belleği; ad, konum ve ilgi alanları gibi semantik bilgilerin açık alanlar altında saklanmasını sağlar.

Bu Dersin Ana Tezi

LangGraph’ta uzun süreli bellek, yalnızca metin saklama problemi değildir. Belleğin güvenilir kullanılabilmesi için store içindeki değerlerin okunabilir, güncellenebilir ve mümkün olduğunca doğrulanabilir bir şema taşıması gerekir.

Öğrenme Hedefleri

  • `TypedDict` ve `BaseModel` ile profil belleği şeması tanımlayabilecek.
  • `InMemoryStore` üzerinde namespace, key ve value ayrımını açıklayabilecek.
  • `with_structured_output` ile konuşmadan yapılandırılmış profil çıkarımını yorumlayabilecek.
  • Karmaşık Pydantic şemalarında doğrulama hatasının neden oluşabileceğini açıklayabilecek.
  • `create_extractor`, `tool_choice` ve `existing` argümanlarının TrustCall içindeki rolünü ayırt edebilecek.
  • `thread_id` ve `user_id` ayrımı üzerinden short-term ve long-term memory ilişkisini yorumlayabilecek.
  • `call_model` ve `write_memory` node’larının graph içindeki sorumluluklarını ayırabilecek.
  • Output bloklarında tool call, parsed schema, store item ve model cevabı ayrımını okuyabilecek.

Ön Koşullar

Python fonksiyonları, dictionary/list yapıları, class tanımı, type hint kullanımı ve temel LLM mesaj kavramları bilinmelidir. `TypedDict`, `BaseModel`, `Field`, namespace, checkpoint ve store kavramları ilk kez görülüyorsa bu derste kısa bağlamlarıyla birlikte ele alınır.

API anahtarı notu

Model çağrıları için API anahtarı gerekir; ancak anahtar değeri kod içine yazılmaz. Ortam değişkeni yaklaşımı, güvenli ve taşınabilir ders kodu için tercih edilir.

Büyük Resim

Bu dersteki zihinsel model üç katmanlıdır: mesaj geçmişi kısa süreli bağlamı taşır, store uzun süreli profili saklar, model veya TrustCall extractor ise konuşmadan şema uyumlu bilgi çıkarır. Graph bu katmanları sıralı node’larla bir araya getirir.

Ana Anlatım

Önce profil belleği basit bir `TypedDict` ile tanımlanır ve store içine yazılır. Ardından modelin structured output yeteneğiyle konuşmadan profil çıkarılır. Bu yaklaşım basit profillerde etkili olsa da iç içe ve daha katı Pydantic şemalarında doğrulama hataları görülebilir. TrustCall bu noktada devreye girer: şemayı tool olarak bağlar, mevcut JSON belgeyi dikkate alır ve profil güncellemesini daha hedefli biçimde yapar.

Temel ayrım

`MessagesState` anlık konuşma state’idir; store’daki profil ise kullanıcıya ait uzun süreli semantik bellektir. Graph yürütmesi sırasında ikisi birlikte kullanılır, fakat aynı veri katmanı değildir.

def _set_env(var: str):
    """
    Prepare an environment variable for the current Python process.

    Args:
        var: Name of the environment variable to check.

    Returns:
        None: Prompts for a missing value and writes it to `os.environ`.

    if not env_value:
        env_value = getpass.getpass(f"{var}: ")

Structured profile kullanan ilk chatbot graph’ı

Bu graph iki node içerir: `call_model` kullanıcıya yanıt üretir, `write_memory` ise konuşma geçmişinden yapılandırılmış profil belleği yazar.

Model node’u, memory node’u ve graph derleme
from IPython.display import Image, display

from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import StateGraph, MessagesState, START, END
from langgraph.store.base import BaseStore

from langchain_core.messages import HumanMessage, SystemMessage, AIMessage
from langchain_core.runnables.config import RunnableConfig

# Chatbot instruction
MODEL_SYSTEM_MESSAGE = """You are a helpful assistant with memory that provides information about the user.
If you have memory for this user, use it to personalize your responses.
Here is the memory (it may be empty): {memory}"""

# Create new memory from the chat history and any existing memory
CREATE_MEMORY_INSTRUCTION = """Create or update a user profile memory based on the user's chat history.
This will be saved for long-term memory. If there is an existing memory, simply update it.
Here is the existing memory (it may be empty): {memory}"""


def call_model(state: MessagesState, config: RunnableConfig, store: BaseStore):
    """Load memory from the store and use it to personalize the chatbot's response."""
    user_id = config["configurable"]["user_id"]

    namespace = ("memory", user_id)
    existing_memory = store.get(namespace, "user_memory")

    if existing_memory and existing_memory.value:
        memory_dict = existing_memory.value
        formatted_memory = (
            f"Name: {memory_dict.get('user_name', 'Unknown')}\n"
            f"Interests: {', '.join(memory_dict.get('interests', []))}"
        )
    else:
        formatted_memory = None

    system_msg = MODEL_SYSTEM_MESSAGE.format(memory=formatted_memory)
    response = model.invoke([SystemMessage(content=system_msg)] + state["messages"])

    return {"messages": response}


def write_memory(state: MessagesState, config: RunnableConfig, store: BaseStore):
    """Reflect on the chat history and save a memory to the store."""
    user_id = config["configurable"]["user_id"]

    namespace = ("memory", user_id)
    existing_memory = store.get(namespace, "user_memory")

    if existing_memory and existing_memory.value:
        memory_dict = existing_memory.value
        formatted_memory = (
            f"Name: {memory_dict.get('user_name', 'Unknown')}\n"
            f"Interests: {', '.join(memory_dict.get('interests', []))}"
        )
    else:
        formatted_memory = None

    system_msg = CREATE_MEMORY_INSTRUCTION.format(memory=formatted_memory)
    new_memory = model_with_structure.invoke(
        [SystemMessage(content=system_msg)] + state["messages"]
    )

    key = "user_memory"
    store.put(namespace, key, new_memory)


builder = StateGraph(MessagesState)
builder.add_node("call_model", call_model)
builder.add_node("write_memory", write_memory)
builder.add_edge(START, "call_model")
builder.add_edge("call_model", "write_memory")
builder.add_edge("write_memory", END)

across_thread_memory = InMemoryStore()
within_thread_memory = MemorySaver()

graph = builder.compile(
    checkpointer=within_thread_memory,
    store=across_thread_memory,
)

display(Image(graph.get_graph(xray=1).draw_mermaid_png()))

Karmaşık profil şeması ve doğrulama sınırı

Profil şemaları büyüdükçe iç içe Pydantic modelleri ve optional listeler artar. Bu örnek, structured output yaklaşımının karmaşık şemalarda neden zorlanabileceğini gösterir.

İç içe Pydantic profil modeli
from typing import List, Optional


class OutputFormat(BaseModel):
    """
    Define the OutputFormat data model.
    """
    preference: str
    sentence_preference_revealed: str


class TelegramPreferences(BaseModel):
    """
    Define the TelegramPreferences data model.
    """
    preferred_encoding: Optional[List[OutputFormat]] = None
    favorite_telegram_operators: Optional[List[OutputFormat]] = None
    preferred_telegram_paper: Optional[List[OutputFormat]] = None


class MorseCode(BaseModel):
    """
    Define the MorseCode data model.
    """
    preferred_key_type: Optional[List[OutputFormat]] = None
    favorite_morse_abbreviations: Optional[List[OutputFormat]] = None


class Semaphore(BaseModel):
    """
    Define the Semaphore data model.
    """
    preferred_flag_color: Optional[List[OutputFormat]] = None
    semaphore_skill_level: Optional[List[OutputFormat]] = None


class TrustFallPreferences(BaseModel):
    """
    Define the TrustFallPreferences data model.
    """
    preferred_fall_height: Optional[List[OutputFormat]] = None
    trust_level: Optional[List[OutputFormat]] = None
    preferred_catching_technique: Optional[List[OutputFormat]] = None


class CommunicationPreferences(BaseModel):
    """
    Define the CommunicationPreferences data model.
    """
    telegram: TelegramPreferences
    morse_code: MorseCode
    semaphore: Semaphore


class UserPreferences(BaseModel):
    """
    Define the UserPreferences data model.
    """
    communication_preferences: CommunicationPreferences
    trust_fall_preferences: TrustFallPreferences


class TelegramAndTrustFallPreferences(BaseModel):
    """
    Define the TelegramAndTrustFallPreferences data model.
    """
    pertinent_user_preferences: UserPreferences

from trustcall import create_extractor

# Schema
class UserProfile(BaseModel):
    """User profile schema with typed fields"""
    user_name: str = Field(description="The user's preferred name")

# Initialize the model

# Create the extractor

)

# Instruction

TrustCall tabanlı memory node’u ve graph
from IPython.display import Image, display

from langchain_core.messages import HumanMessage, SystemMessage
from langgraph.graph import StateGraph, MessagesState, START, END
from langchain_core.runnables.config import RunnableConfig
from langgraph.checkpoint.memory import MemorySaver
from langgraph.store.base import BaseStore

# Initialize the model
model = ChatOpenAI(model="gpt-4o", temperature=0)

# Schema
class UserProfile(BaseModel):
    """ Profile of a user """
    user_name: str = Field(description="The user's preferred name")
    user_location: str = Field(description="The user's location")
    interests: list = Field(description="A list of the user's interests")


# Create the extractor
trustcall_extractor = create_extractor(
    model,
    tools=[UserProfile],
    tool_choice="UserProfile",  # Enforces use of the UserProfile tool
)

# Chatbot instruction
MODEL_SYSTEM_MESSAGE = """You are a helpful assistant with memory that provides information about the user.
If you have memory for this user, use it to personalize your responses.
Here is the memory (it may be empty): {memory}"""

# Extraction instruction
TRUSTCALL_INSTRUCTION = """Create or update the memory (JSON doc) to incorporate information from the following conversation:"""


def call_model(state: MessagesState, config: RunnableConfig, store: BaseStore):
    """Load memory from the store and use it to personalize the chatbot's response."""
    user_id = config["configurable"]["user_id"]

    namespace = ("memory", user_id)
    existing_memory = store.get(namespace, "user_memory")

    if existing_memory and existing_memory.value:
        memory_dict = existing_memory.value
        formatted_memory = (
            f"Name: {memory_dict.get('user_name', 'Unknown')}\n"
            f"Location: {memory_dict.get('user_location', 'Unknown')}\n"
            f"Interests: {', '.join(memory_dict.get('interests', []))}"
        )
    else:
        formatted_memory = None

    system_msg = MODEL_SYSTEM_MESSAGE.format(memory=formatted_memory)
    response = model.invoke([SystemMessage(content=system_msg)] + state["messages"])

    return {"messages": response}


def write_memory(state: MessagesState, config: RunnableConfig, store: BaseStore):
    """Reflect on the chat history and save a memory to the store."""
    user_id = config["configurable"]["user_id"]

    namespace = ("memory", user_id)
    existing_memory = store.get(namespace, "user_memory")
    existing_profile = {"UserProfile": existing_memory.value} if existing_memory else None

    result = trustcall_extractor.invoke(
        {
            "messages": [SystemMessage(content=TRUSTCALL_INSTRUCTION)]
            + state["messages"],
            "existing": existing_profile,
        }
    )

    updated_profile = result["responses"][0].model_dump()

    key = "user_memory"
    store.put(namespace, key, updated_profile)


builder = StateGraph(MessagesState)
builder.add_node("call_model", call_model)
builder.add_node("write_memory", write_memory)
builder.add_edge(START, "call_model")
builder.add_edge("call_model", "write_memory")
builder.add_edge("write_memory", END)

across_thread_memory = InMemoryStore()
within_thread_memory = MemorySaver()

graph = builder.compile(
    checkpointer=within_thread_memory,
    store=across_thread_memory,
)

display(Image(graph.get_graph(xray=1).draw_mermaid_png()))

Çıktıların Yorumlanması

Bu derste çıktılar dört gruba ayrılır. Dict çıktıları store’da saklanan profil değerini gösterir. Message çıktıları graph’ın konuşma state’ine eklediği insan ve asistan mesajlarını gösterir. Tool call çıktıları TrustCall’ın şema uyumlu argüman üretimini gösterir. Validation çıktısı ise karmaşık şemada doğrudan structured output yaklaşımının başarısız olduğu noktayı gösterir.

Okuma rehberi

Bir output bloğunda `user_name`, `user_location` veya `interests` alanları görülüyorsa bu profil belleği katmanıdır. `Human Message` ve `Ai Message` başlıkları görülüyorsa konuşma state’i okunmaktadır. `Tool Calls` satırı görülüyorsa model, bir şema/tool çağrısı üretmiştir.

Graph Akışı

Her iki chatbot graph’ında topoloji aynıdır. Değişen nokta, `write_memory` node’unun profili nasıl ürettiğidir: ilk sürümde doğrudan structured output, son sürümde TrustCall extractor kullanılır.

STARTGraph yürütmesi kullanıcı mesajlarıyla başlar.
call_modelStore’dan profil okur ve modeli kişiselleştirilmiş sistem mesajıyla çağırır.
write_memoryKonuşmadan profil çıkarır veya mevcut profili günceller.
ENDYürütme, mesaj state’i ve güncellenmiş store ile tamamlanır.

State’in Evrimi

Başlangıç input’u`{"messages": input_messages}` graph’a verilir. Mesaj listesi `MessagesState` içinde taşınır.
Model cevabı`call_model`, `{"messages": response}` döndürerek state’e asistan cevabı ekler.
Store okuma`store.get(("memory", user_id), "user_memory")` uzun süreli profili okur; bu değer state alanı değildir.
Store yazma`store.put(namespace, key, updated_profile)` profili uzun süreli belleğe yazar.
Thread ayrımı`thread_id` kısa süreli konuşma geçmişini ayırır.
Kullanıcı ayrımı`user_id` aynı kaldığında profil yeni thread’de de erişilebilir kalır.

Agent / Tool Etkileşimi

Bu derste tam bir dış araç kullanan agent döngüsü kurulmaz. Ancak TrustCall, profil şemasını tool calling biçiminde modele bağlar. Bu yüzden görülen `Tool Calls` çıktısı, dış dünyada işlem yapan bir araç sonucundan çok, şema uyumlu argüman üretimi olarak okunmalıdır.

Kullanıcı mesajlarıProfil çıkarımı için doğal dil sinyali sağlar.
Model / extractorŞema adına uygun tool call argümanları üretir.
Parsed responseTool call argümanları Pydantic nesnesine veya dict yapısına dönüştürülür.

Yaygın Hatalar

  • Store’daki uzun süreli belleği `MessagesState` içindeki kısa süreli mesaj geçmişiyle aynı sanmak.
  • `thread_id` değişince profil belleğinin de silineceğini düşünmek.
  • `user_id` namespace düzenini tutarsız kullanarak belleği yanlış yerde aramak.
  • `TypedDict` tanımını runtime doğrulama mekanizması sanmak.
  • Structured output başarısız olduğunda bunun yalnızca model kapasitesiyle çözüleceğini varsaymak.
  • Tool call çıktısını doğrudan kullanıcıya verilen nihai cevap gibi yorumlamak.
  • `existing` profil verilmeden yapılan çıkarımı güncelleme sanmak.
  • `model_dump()` ile elde edilen dict temsilini Pydantic nesnesiyle aynı katman olarak görmek.
  • Output bloklarındaki message çıktısı ile store item çıktısını karıştırmak.
  • API anahtarını kod içine yazmak.

Son Çıkarımlar

  1. Profil belleği, serbest metinden daha güvenilir bir uzun süreli bellek biçimi sağlar.
  2. `InMemoryStore`, namespace ve key üzerinden kullanıcıya ait profil değerini saklar.
  3. `MessagesState`, konuşma state’idir; store value ise threadler arası bellektir.
  4. `with_structured_output`, basit şemalarda doğrudan profil çıkarımı için yeterli olabilir.
  5. Karmaşık Pydantic şemalarında doğrulama hataları beklenmelidir.
  6. TrustCall, şemayı tool olarak kullanarak çıkarım ve güncelleme sürecini daha dayanıklı hale getirir.
  7. `existing` profil bilgisi, belleğin baştan yazılması yerine hedefli güncellenmesine yardım eder.
  8. `thread_id` kısa süreli belleği, `user_id` uzun süreli kullanıcı belleğini belirler.
  9. `call_model` kişiselleştirilmiş cevap üretir; `write_memory` profil belleğini günceller.
  10. Yeni thread’de kişiselleştirilmiş cevap alınması, profil belleğinin store’dan başarıyla okunduğunu gösterir.

# Schema
class UserProfile(BaseModel):
    """ Profile of a user """
    user_name: str = Field(description="The user's preferred name")
    user_location: str = Field(description="The user's location")
    interests: list = Field(description="A list of the user's interests")


# Create the extractor
trustcall_extractor = create_extractor(
    model,
    tools=[UserProfile],
    tool_choice="UserProfile",  # Enforces use of the UserProfile tool
)

# Chatbot instruction
MODEL_SYSTEM_MESSAGE = """You are a helpful assistant with memory that provides information about the user.
If you have memory for this user, use it to personalize your responses.
Here is the memory (it may be empty): {memory}"""

# Extraction instruction
TRUSTCALL_INSTRUCTION = """Create or update the memory (JSON doc) to incorporate information from the following conversation:"""


def call_model(state: MessagesState, config: RunnableConfig, store: BaseStore):
    """Load memory from the store and use it to personalize the chatbot's response."""
    user_id = config["configurable"]["user_id"]

    namespace = ("memory", user_id)
    existing_memory = store.get(namespace, "user_memory")

    if existing_memory and existing_memory.value:
        memory_dict = existing_memory.value
        formatted_memory = (
            f"Name: {memory_dict.get('user_name', 'Unknown')}\n"
            f"Location: {memory_dict.get('user_location', 'Unknown')}\n"
            f"Interests: {', '.join(memory_dict.get('interests', []))}"
        )
    else:
        formatted_memory = None

    system_msg = MODEL_SYSTEM_MESSAGE.format(memory=formatted_memory)
    response = model.invoke([SystemMessage(content=system_msg)] + state["messages"])

    return {"messages": response}


def write_memory(state: MessagesState, config: RunnableConfig, store: BaseStore):
    """Reflect on the chat history and save a memory to the store."""
    user_id = config["configurable"]["user_id"]

    namespace = ("memory", user_id)
    existing_memory = store.get(namespace, "user_memory")
    existing_profile = {"UserProfile": existing_memory.value} if existing_memory else None

    result = trustcall_extractor.invoke(
        {
            "messages": [SystemMessage(content=TRUSTCALL_INSTRUCTION)]
            + state["messages"],
            "existing": existing_profile,
        }
    )

    updated_profile = result["responses"][0].model_dump()

    key = "user_memory"
    store.put(namespace, key, updated_profile)
