LangGraph’ta Özetlemeli Chatbot Belleği

Bu ders, uzun konuşmaları yalnızca kırpmak yerine LLM tabanlı çalışan bir özet alanıyla sıkıştırmayı; bu özeti LangGraph state’i, conditional edge ve MemorySaver checkpointer ile kalıcı chatbot belleğine dönüştürmeyi açıklar.

Kapsam ve Bağlam

Önceki mesaj yönetimi yaklaşımlarında konuşma geçmişi ya doğrudan filtrelenir ya da belirli sayıda mesajla sınırlandırılır. Bu ders, aynı problemi daha bilgi koruyucu bir yöntemle ele alır: eski konuşma ayrıntıları tamamen atılmak yerine, model tarafından üretilen çalışan bir özet alanına aktarılır.

Bu Dersin Ana Tezi

MessagesState yalnızca ham mesaj listesini taşımak zorunda değildir. Özel bir summary alanı eklenerek uzun konuşmanın sıkıştırılmış temsili state içinde saklanabilir; MemorySaver ise bu state’i thread bazında sonraki graph çağrılarına taşır.

Öğrenme Hedefleri

  • MessagesState sınıfını özel summary alanıyla genişletebilmek.
  • Bir chatbot node’unun mevcut özeti model prompt’una nasıl eklediğini açıklayabilmek.
  • Özetleme node’unda mevcut summary bilgisinin nasıl genişletildiğini yorumlayabilmek.
  • RemoveMessage ile eski mesajları state’ten id tabanlı silme mantığını açıklayabilmek.
  • should_continue fonksiyonuyla conditional edge routing kararını takip edebilmek.
  • MemorySaver, thread_id ve checkpoint kavramlarıyla çok turlu konuşma sürekliliği kurabilmek.
  • Ham mesaj geçmişi, çalışan özet ve kalıcı thread belleği arasındaki farkları ayırt edebilmek.

Ön Koşullar

Bu ders için Python fonksiyonları, dictionary/list yapıları, class genişletme, type hint okuma ve temel chat message kavramları bilinmelidir. LangGraph tarafında node, edge, conditional edge, MessagesState, reducer, compile ve invoke kavramlarının temel düzeyde anlaşılması beklenir.

Ana Anlatım

Filtreleme Yerine Özetleme

Mesaj kırpma, eski konuşmanın ayrıntılarını kaldırarak token kullanımını azaltır. Özetleme ise bu ayrıntıları model tarafından üretilmiş daha kısa bir temsile dönüştürür. Bu nedenle özetleme, özellikle uzun süren chatbot konuşmalarında daha bilgi koruyucu bir sıkıştırma stratejisidir.

Summary Alanının State İçindeki Rolü

summary alanı, messages listesinin yerine geçmez. Yakın bağlam için son mesajlar tutulur; daha eski konuşma ise özet içinde taşınır. Böylece model hem son konuşma turunu hem de önceki bağlamın sıkıştırılmış temsilini görebilir.

Persistence ile Çok Turlu Konuşma

LangGraph state’i tek bir graph yürütmesi içinde geçicidir. Checkpointer kullanıldığında her adım sonrası state saklanır. Aynı thread_id ile yapılan sonraki çağrılar bu saklanan state üzerinden devam eder.

Önemli Tasarım Kararı

Bu derste özetleme koşulu mesaj sayısına göre belirlenir: len(messages) > 6. Bu eşik öğretici amaçlıdır. Üretim sistemlerinde token sayısı, model context window sınırı, maliyet ve cevap gecikmesi gibi ölçütlerle ayarlanmalıdır.

Özeti modele bağlama: call_model node’u

Bu node, state içinde daha önce üretilmiş bir özet varsa onu sistem mesajı olarak yeni model çağrısına ekler.

Özeti modele bağlama: call_model node’u
from langchain_core.messages import HumanMessage, RemoveMessage, SystemMessage


# Define the logic to call the model
def call_model(state: State):
    """
    Run the call_model graph node.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    # Get summary if it exists
    summary = state.get("summary", "")

    # If there is summary, then we add it
    if summary:
        # Add summary to system message
        system_message = f"Summary of conversation earlier: {summary}"

        # Append summary to any newer messages
        messages = [SystemMessage(content=system_message)] + state["messages"]
    else:
        messages = state["messages"]

    response = model.invoke(messages)
    return {"messages": response}

Blok bazlı açıklama

Node, state.get("summary", "") ile özet yokluğunu güvenli şekilde ele alır. Özet varsa SystemMessage, mevcut mesajların önüne eklenir.

LangGraph açısından önemi

Uzun konuşma geçmişi tamamen taşınmasa bile model, önceki bağlamın sıkıştırılmış temsilini görebilir.

Dikkat edilmesi gereken nokta

Bu node summary üretmez; yalnızca varsa mevcut özeti prompt bağlamına ekler ve model yanıtını messages kanalına döndürür.

Konuşma özetini üretme ve eski mesajları temizleme

Bu node, mevcut konuşmadan yeni bir özet üretir. Eğer önceki özet varsa onu genişletir; ardından en son iki mesaj dışındakiler için silme komutu döndürür.

Konuşma özetini üretme ve eski mesajları temizleme
def summarize_conversation(state: State):
    """
    Run the summarize_conversation helper.

    Args:
        state: Current graph state.
    """
    # First, we get any existing summary
    summary = state.get("summary", "")

    # Create our summarization prompt
    if summary:
        # A summary already exists
        summary_message = (
            f"This is summary of the conversation to date: {summary}\n\n"
            "Extend the summary by taking into account the new messages above:"
        )
    else:
        summary_message = "Create a summary of the conversation above:"

    # Add prompt to our history
    messages = state["messages"] + [HumanMessage(content=summary_message)]
    response = model.invoke(messages)

    # Delete all but the 2 most recent messages
    delete_messages = [RemoveMessage(id=m.id) for m in state["messages"][:-2]]
    return {"summary": response.content, "messages": delete_messages}

Blok bazlı açıklama

Bu tasarım, eski konuşmayı metinsel bir özete sıkıştırır ve son iki mesajı ham biçimde koruyarak yakın bağlamı kaybetmemeye çalışır.

LangGraph açısından önemi

summary alanı uzun vadeli bağlamı saklarken RemoveMessage state içindeki ayrıntılı geçmişi daraltır.

Dikkat edilmesi gereken nokta

RemoveMessage doğrudan liste elemanı silmek değildir; reducer tarafından id tabanlı silme isteği olarak yorumlanır.

Koşullu rota: ne zaman özet üretilecek?

Bu fonksiyon, mesaj sayısı altıdan büyük olduğunda summarization node’una; aksi halde graph bitişine yönlendirir.

Koşullu rota: ne zaman özet üretilecek?
from langgraph.graph import END
from typing_extensions import Literal


# Determine whether to end or summarize the conversation
def should_continue(state: State) -> Literal["summarize_conversation", END]:
    """Return the next node to execute."""
    messages = state["messages"]

    # If there are more than six messages, then we summarize the conversation
    if len(messages) > 6:
        return "summarize_conversation"

    # Otherwise we can just end
    return END

LangGraph açısından önemi

add_conditional_edges içinde kullanılacak routing fonksiyonu graph’ın devam edip etmeyeceğini belirler.

Dikkat edilmesi gereken nokta

Eşik değeri örnek amaçlıdır; gerçek uygulamalarda token bütçesi, model context window sınırı veya ürün ihtiyacıyla ayarlanmalıdır.

MemorySaver ile özetlemeli graph kurma

Bu blok, iki node’lu graph’ı kurar: önce model yanıtı üretilir, ardından mesaj sayısına göre özetleme node’una geçilip geçilmeyeceği belirlenir.

MemorySaver ile özetlemeli graph kurma
from IPython.display import Image, display
from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import START, StateGraph

# Define a new graph
workflow = StateGraph(State)
workflow.add_node("conversation", call_model)
workflow.add_node(summarize_conversation)

# Set the entrypoint as conversation
workflow.add_edge(START, "conversation")
workflow.add_conditional_edges("conversation", should_continue)
workflow.add_edge("summarize_conversation", END)

# Compile
memory = MemorySaver()
graph = workflow.compile(checkpointer=memory)
display(Image(graph.get_graph().draw_mermaid_png()))

LangGraph açısından önemi

MemorySaver checkpointer, thread bazlı çağrılar arasında state’in yeniden kullanılmasını sağlar.

Dikkat edilmesi gereken nokta

Graph belleği compile(checkpointer=memory) ile etkinleşir; yalnızca MemorySaver() oluşturmak yeterli değildir.

Agent / Tool Etkileşimi

Bu derste tool execution loop kurulmaz. Ancak kullanılan yapı agent sistemleri için doğrudan önemlidir: uzun konuşma geçmişi olan agent’larda tool sonuçları, kullanıcı mesajları ve model cevapları hızla büyüyebilir. Bu dersteki summary + checkpointer tasarımı, daha sonra tool kullanan agent’ların bağlam yönetimi için temel oluşturur.

Kullanıcıhi! I'm Lance
AssistantHello Lance! How can I assist you today?
Kullanıcıwhat's my name?
AssistantYou mentioned that your name is Lance.
Kullanıcıi like Nick Bosa...
StateKonuşma eşiği aşılınca summary alanı güncellenir.

Yaygın Hatalar

  • summary alanını mesaj listesinin yerine geçen tam bellek sanmak.
  • RemoveMessage nesnelerini doğrudan liste silme işlemi gibi düşünmek.
  • MemorySaver oluşturup graph’a compile(checkpointer=...) ile vermeyi unutmak.
  • Her invocation’da aynı thread_id değerini kullanmadığında konuşmanın devam etmeyeceğini gözden kaçırmak.
  • Özetleme eşiğini sabit ve evrensel bir kural sanmak.
  • Model cevabı ile state summary güncellemesini aynı çıktı zannetmek.
  • LangSmith tracing’i state persistence mekanizması sanmak.
  • Özet model tarafından üretildiği için kelime düzeyinde deterministik olmayabileceğini unutmak.

Son Çıkarımlar

  1. MessagesState, hazır mesaj kanalına ek özel alanlarla genişletilebilir.
  2. summary alanı, uzun konuşmanın sıkıştırılmış temsilini state içinde taşır.
  3. SystemMessage, mevcut summary bilgisini model çağrısına bağlam olarak eklemek için kullanılabilir.
  4. summarize_conversation node’u hem summary üretir hem eski mesajları temizleme komutu döndürür.
  5. RemoveMessage, reducer tarafından işlenen id tabanlı bir silme isteğidir.
  6. should_continue, mesaj sayısına göre conditional edge rotasını belirler.
  7. MemorySaver, graph state’ini thread bazında saklayarak çok turlu konuşma sürekliliği sağlar.
  8. thread_id olmadan ayrı graph çağrıları aynı konuşma hattına bağlanmaz.
  9. Özetleme, kırpmaya göre daha bilgi koruyucu bir context compression stratejisidir.
  10. Bu yapı tool kullanan daha karmaşık agent’larda da bağlam yönetimi için temel oluşturur.

from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-4o", temperature=0)

from langgraph.graph import MessagesState


class State(MessagesState):
    """
    Define the state schema used by the graph.
    """
    summary: str

from langchain_core.messages import HumanMessage, RemoveMessage, SystemMessage


# Define the logic to call the model
def call_model(state: State):
    """
    Run the call_model graph node.

    Args:
        state: Current graph state.

    Returns:
        Value produced for the surrounding example.
    """
    # Get summary if it exists
    summary = state.get("summary", "")

    # If there is summary, then we add it
    if summary:
        # Add summary to system message
        system_message = f"Summary of conversation earlier: {summary}"

        # Append summary to any newer messages
        messages = [SystemMessage(content=system_message)] + state["messages"]
    else:
        messages = state["messages"]

    response = model.invoke(messages)
    return {"messages": response}

def summarize_conversation(state: State):
    """
    Run the summarize_conversation helper.

    Args:
        state: Current graph state.
    """
    # First, we get any existing summary
    summary = state.get("summary", "")

    # Create our summarization prompt
    if summary:
        # A summary already exists
        summary_message = (
            f"This is summary of the conversation to date: {summary}\n\n"
            "Extend the summary by taking into account the new messages above:"
        )
    else:
        summary_message = "Create a summary of the conversation above:"

    # Add prompt to our history
    messages = state["messages"] + [HumanMessage(content=summary_message)]
    response = model.invoke(messages)

    # Delete all but the 2 most recent messages
    delete_messages = [RemoveMessage(id=m.id) for m in state["messages"][:-2]]
    return {"summary": response.content, "messages": delete_messages}

from langgraph.graph import END
from typing_extensions import Literal


# Determine whether to end or summarize the conversation
def should_continue(state: State) -> Literal["summarize_conversation", END]:
    """Return the next node to execute."""
    messages = state["messages"]

    # If there are more than six messages, then we summarize the conversation
    if len(messages) > 6:
        return "summarize_conversation"

    # Otherwise we can just end
    return END

from IPython.display import Image, display
from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import START, StateGraph

# Define a new graph
workflow = StateGraph(State)
workflow.add_node("conversation", call_model)
workflow.add_node(summarize_conversation)

# Set the entrypoint as conversation
workflow.add_edge(START, "conversation")
workflow.add_conditional_edges("conversation", should_continue)
workflow.add_edge("summarize_conversation", END)

# Compile
memory = MemorySaver()
graph = workflow.compile(checkpointer=memory)
